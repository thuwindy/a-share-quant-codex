# 因子入库前检查清单

| 检查项 | 最低要求 |
| --- | --- |
| 时间对齐 | 不能用未来数据 |
| 缺失率 | 不要高到影响大面积股票覆盖 |
| 排序能力 | 前 5% / 10% / 20% 命中率要明显高于底盘 |
| 重复度 | 和 `momentum_20_neu` / `momentum_60_neu` 不能只是同义重复 |
| 候选池增量 | 主策略前 20 内重排或过滤后，真实可买票要变好 |
| 解释性 | 能说清为什么有效 |

## 一票否决

| 情况 | 处理 |
