# Security Policy

This repository is intended to be open-source safe.

Do not commit:

- API keys, tokens, passwords, cookies, or private endpoints.
- Personal filesystem paths, SSH keys, cloud server IPs, or cron logs.
- Proprietary market data, paid data exports, generated model files, or runtime outputs.

Use `.env.example` as the template for local configuration and keep real credentials in environment variables or an untracked `.env` file.
