# 面向 A 股的量化系统设计

## 1. 目标

构建一个**研究优先**的 A 股量化系统，支持：

- 截面因子研究
- 因子中性化与风险控制
- 组合构建
- 日频回测
- 用 Codex 自动化重复研究工作

## 2. 总体架构

```text
数据层 -> 因子层 -> 标签层 -> 模型层 -> 组合层 -> 回测层 -> 报告层
                                    ^
                                    |
                             Agent / Codex 协作层
```

## 3. 模块说明

### 3.1 数据层

输入建议至少包括：

- 日频 OHLCV
- 市值 / 行业
- ST / 停牌标记
- 涨跌停可交易标记
- 基本面（季频 / 年频）
- 分析师预期（可选）

当前原型已经补了 `MarketDataSource` 抽象，默认实现仍是 `CSVDataSource`。后续可扩展：

- `AkshareDataSource`
- `TushareDataSource`
- `WindDataSource`

### 3.2 因子层

当前内置 5 类轻量因子：

- `momentum_20`
- `reversal_5`
- `quality_20`
- `liquidity_20`
- `volatility_20`

生产系统建议扩展到：

- 基本面因子
- 预期差因子
- 事件因子
- 行业内相对强弱
- 微观结构因子

### 3.3 标签层

当前使用 `forward_return_5d`。

后续可扩展：

- 未来 1/5/10/20 日收益
- 相对基准超额收益
- 分类标签（上涨/下跌）
- 排序标签（rank target）

### 3.4 模型层

当前原型用“训练期平均 IC 作为因子权重”的线性打分器。

后续可扩展：

- Ridge / Lasso
- LightGBM 排序
- XGBoost
- 深度学习排序器
- 集成模型

### 3.5 风控层

当前实现：

- 市值 + 行业中性化
- 基础可交易性筛选

建议升级：

- 风格暴露约束
- 行业权重约束
- 单票上限
- 换手惩罚
- 成交额容量约束

### 3.6 组合层

当前实现：

- Top-N long-only
- 等权持仓
- 固定频率调仓

建议升级：

- benchmark relative
- 指数增强
- 风险预算
- mean-variance / robust optimization
- 黑利特曼或风险平价近似方案

### 3.7 回测层

当前是 research-grade 近似模型，适合课程项目与原型验证。

生产版需要增加：

- 真正的 next-open / close 执行逻辑
- 涨跌停不可买不可卖处理
- 停牌冻结仓位
- 分红、送转、复权一致性
- 成交量约束和冲击成本
- 基准对比与 tracking error

另外，仓库里已经增加了一个轻量 `PaperExecutionAdapter`，用于把研究输出接到 mock order / fill 记录层，但它还不是完整的订单管理与实盘执行系统。

## 4. A 股特有约束

系统默认必须考虑：

1. T+1
2. ST / *ST 筛除
3. 停牌不可交易
4. 涨跌停导致买卖受限
5. 成交额容量与滑点
6. 集合竞价与非连续成交时段

## 5. 研究流程

推荐标准流程：

1. 选择股票池（全 A / 中证 500 / 沪深 300 / 行业内）
2. 清洗数据
3. 计算因子
4. 做中性化与标准化
5. 生成标签
6. 样本切分（train / valid / test）
7. 估计因子权重或训练模型
8. 构建组合
9. 回测
10. 生成研究报告

## 6. Codex 在系统中的位置

Codex 不是“策略本体”，而是**研究操作系统**：

- 写因子代码
- 补测试
- 审计未来函数
- 批量比较实验结果
- 自动整理回测输出
- 维护项目知识与约束

因此本仓库把 Codex 接入点放在两处：

### 6.1 `AGENTS.md`

定义项目级长期规则。

### 6.2 `skills/`

把重复研究工作固化成技能：

- 新增因子
- 审计回测
- 生成研究报告

## 7. 课程项目建议里程碑

### M1：基础可运行

- 能读数据
- 能算因子
- 能跑最小回测

### M2：A 股约束补齐

- 加 ST / 停牌 / 成本 / 交易限制

### M3：研究标准化

- 加分层回测
- 加 IC / ICIR
- 加滚动训练

### M4：Codex 自动化

- 加 AGENTS.md
- 加 skills
- 固化“改因子 -> 跑回测 -> 写报告”流程

### M5：项目答辩版

- baseline
- ablation
- 样本外表现
- 失败案例分析
