# 从研究原型到可投入使用的 A 股量化机器人

## 先说结论

当前仓库是**研究原型**，不是直接可实盘的交易系统。

它已经把最重要的研究链路搭出来了，但距离“可投入使用”还需要补 4 个大层：

1. 真实数据层
2. 更真实的回测/执行层
3. 风控与监控层
4. 运维与合规层

## 1. 三阶段路线图

### 阶段 A：Research-grade

目标：证明研究链路成立。

现有能力：

- 因子研究
- 中性化
- 标签生成
- 组合构建
- 简单回测
- Codex 协作

阶段产物：

- 因子有效性报告
- baseline 比较
- 样本内外实验

### 阶段 B：Production-sim

目标：让结果更接近真实可交易状态。

需要增加：

- 真实 A 股数据接口
- 复权与 corporate actions 处理
- next-open / VWAP / close 执行假设
- 涨跌停不可成交逻辑
- 停牌冻结持仓逻辑
- 容量约束与成交额约束
- benchmark / tracking error / 风格暴露监控

阶段产物：

- 仿生产回测报告
- 风险暴露报告
- 容量与成本敏感性分析

### 阶段 C：Live-trading Robot

目标：小规模灰度实盘。

需要增加：

- 实盘 broker / OMS / PMS 接口
- 下单风控
- 盘前选股、盘中执行、盘后归因
- 调度系统
- 日志、告警、回滚
- 账户与仓位监控
- 失败重试与人工接管

阶段产物：

- 纸面交易 / 模拟盘
- 小资金灰度实盘
- 日报与监控看板

## 2. 实盘机器人最少模块

```text
数据采集 -> 特征/标签 -> 预测/打分 -> 组合优化 -> 下单前风控 -> 执行适配 -> 盘后归因 -> 监控与告警
```

### 2.1 数据采集

至少需要：

- 日频行情
- 行业、市值、ST、停牌
- 可买卖标记
- 基本面
- 公司行为（分红、送转、拆合）

### 2.2 研究与信号

建议保留两套信号：

- 主信号：多因子横截面排名
- 保护信号：风控降杠杆 / 降换手 / 市场状态过滤

### 2.3 组合优化

至少要支持：

- 单票权重上限
- 行业偏离上限
- 风格暴露上限
- 换手预算
- 容量约束

### 2.4 下单前风控

至少检查：

- ST
- 停牌
- 涨跌停
- 黑名单股票
- 账户仓位边界
- 单日成交额占比

### 2.5 执行适配

需要一个 execution adapter，负责：

- 把目标权重转成订单
- 处理未成交/部分成交
- 回传成交回报
- 重算剩余目标

### 2.6 盘后归因与监控

至少输出：

- 当日收益归因
- 行业/风格暴露
- 换手
- 滑点与成本
- 异常交易日志

## 3. 真实数据接入优先级

### 优先级 1：先接日频与元数据

- OHLCV
- 行业
- 市值
- ST / 停牌
- 涨跌停可交易标记

### 优先级 2：再接基本面

- PB / PE / PS / PCF
- ROE / ROA / 毛利率 / 净利率
- 营收增长 / 净利增长

### 优先级 3：最后接高成本数据

- 分析师预期
- 公告文本
- 另类数据
- 高频 / L2

## 4. 技术栈建议

### 本地研发

- Python
- pandas / numpy / scipy
- lightgbm / xgboost
- DuckDB
- matplotlib

### 数据与调度

- DuckDB / PostgreSQL / ClickHouse
- Airflow / Dagster / Prefect
- Parquet 分区存储

### 服务与监控

- FastAPI
- Docker
- Prometheus + Grafana
- Sentry / ELK / OpenTelemetry

## 5. 让 Codex 参与生产化的正确方式

Codex 适合做：

- 写适配器
- 写测试
- 整理日志解析器
- 写告警规则
- 维护 runbook 和日报模板

Codex 不适合单独决定：

- 最终交易参数
- 风险边界
- 异常情况下是否继续下单

## 6. 推荐升级顺序

### 第 1 优先级

- 真实数据适配器
- 更真实回测
- 分层/IC/walk-forward

### 第 2 优先级

- LightGBM / XGBoost 排序器
- 风险约束组合优化
- benchmark-relative 评估

### 第 3 优先级

- execution adapter
- 调度与监控
- 模拟盘 / 小资金灰度

## 7. 什么时候才算“能够投入使用”

建议至少同时满足下面 8 条：

1. 样本外表现稳定
2. 成本后仍有显著优势
3. 回测与仿真结果一致性较高
4. 能处理停牌/涨跌停/未成交
5. 有账户级风控
6. 有告警与回滚
7. 有人工接管流程
8. 连续运行足够长时间无严重故障

## 8. 一条务实路线

如果你的目标是真做出能用的机器人，最务实的路线是：

1. 先把这个仓库做成优秀课程项目
2. 再接真实 A 股数据做仿生产版
3. 再接模拟盘或 paper trading
4. 最后才做小资金实盘

不要跳过中间层。
