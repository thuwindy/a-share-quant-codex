# 学习资料梳理：从量化基础到金融机器学习，再到 Agent / Codex

## 1. 三份 PPT 的主线关系

### Lec2：量化投资基础

这部分回答“量化系统最底层需要懂什么”。重点不是模型，而是：

- 市场对象：股票、指数、ETF、股指期货、期权
- A 股制度差异：集合竞价、T+1、行业分类、公告、基本面/技术面
- 数据形态：K 线、LOB、tick、level1、level2、TWAP、VWAP
- 绩效指标：年化收益、超额收益、最大回撤、波动率、Sharpe、Calmar
- 信号评估：IC、ICIR、IR、分层回测
- 经典技术策略：MA、RSI、Bollinger、网格、马丁等

一句话：**Lec2 是“交易对象 + 数据 + 指标 + 基本策略范式”的地基。**

## 2. Lec3：因子投资与金融机器学习

这部分回答“为什么可以系统化地做选股”。主线是：

### 2.1 因子模型的两个视角

- **归因模型（Ex-post）**：解释过去收益从哪里来
- **预测模型（Ex-ante）**：预测未来收益往哪里去

对系统建设而言，研究平台更关心**预测模型**，风控与组合解释更关心**归因模型**。

### 2.2 必学理论框架

- CAPM
- 线性多因子模型
- Fama-French 3 因子 / 5 因子
- Carhart 动量四因子
- 因子中性化与正交化
- 学术界（时间序列估计） vs 业界（横截面回归）

### 2.3 业界真正关心什么

业界不执着“完美可解释的共识因子”，更关心：

- 因子是否能稳定预测未来收益
- 是否可交易
- 是否考虑交易成本
- 是否会衰减
- 是否和已有因子高度重合

### 2.4 因子分类

- 估值
- 盈利
- 营运
- 成长
- 现金流
- 分析师预期
- 技术因子
- 高频/微观结构
- 另类数据

### 2.5 金融机器学习完整流程

一个合格的量化研究流程不是“训练一个模型”就结束，而是：

1. 数据准备：补全、筛选、增强
2. 特征构造：人工因子、自动化特征挖掘
3. 标签设计：未来 1/5/10/20 日收益、相对收益、分类标签等
4. 模型训练：线性模型、树模型、深度学习、排序模型
5. 风险建模：风格、行业、市值等风险暴露控制
6. 信号到决策：打分、分层、组合构建、调仓
7. 回测与过拟合判断：IC、Sharpe、MDD、换手、成本、稳定性

### 2.6 一个非常重要的警告：Factor Zoo

“因子动物园”说明：

- 文献里能写出来的因子很多
- 但很多是 data mining / p-hacking 产物
- 新因子必须通过更严格的统计与样本外验证

所以系统设计必须默认：

- 因子会失效
- 因子会拥挤
- 研究流程必须可复验、可回滚、可批量比较

## 3. Lec4：大模型、Agent 与 Codex

这部分回答“怎样把研究流程自动化”。

### 3.1 大模型真正能做什么

- 读代码、写代码、补测试、写文档
- 搜索资料、整理研究结论
- 生成因子草案和解释
- 协助做实验编排
- 通过工具调用把“语言能力”接到真实计算系统上

### 3.2 大模型不能直接替代什么

- 精确计算
- 最新行情真值
- 严格回测结论
- 交易约束校验

因此正确架构应该是：

- **LLM / Codex 负责研究协作与流程自动化**
- **Python / 数据库 / 回测引擎负责计算与执行**

### 3.3 关键概念

- CoT：让模型分步思考
- ToT：树状探索解题路径
- RAG：把外部知识接进模型
- ReAct：思考 + 工具调用
- MCP：统一的工具/上下文接入协议
- Skills：可复用的工作流模块
- Multi-Agent / Subagents：把复杂任务拆成并行角色

### 3.4 和量化最相关的 Agent 方向

- Agent for Factor Mining
- AlphaGPT
- FactorMAD
- R&D-Agent / 自动实验系统

这些工作说明：**LLM 在量化里最有价值的位置，是“研究员协作层”和“实验自动化层”，而不是直接替代交易引擎。**

## 4. 建议的学习顺序

### 第一步：打地基

先学会：

- 收益率、复利、回撤、Sharpe
- IC / ICIR / 分层回测
- A 股交易约束
- 常用技术指标

### 第二步：建立因子观

重点掌握：

- 因子暴露 / 因子收益 / 归因
- FF3 / FF5 / 动量因子
- 中性化 / 正交化
- 行业 / 市值 / 风格风险控制

### 第三步：进入机器学习研究流程

重点掌握：

- 标签设计
- Walk-forward / 样本内外切分
- 过拟合检查
- 成本与换手约束
- 因子组合与模型集成

### 第四步：再接入 Agent / Codex

重点不是“让 LLM 预测股票”，而是：

- 让 Codex 管理代码与实验
- 让技能（skills）固定研究流程
- 让 subagents 并行做审计、实现、测试、报告

## 5. 从课程到项目的映射

把课程内容映射到一个 A 股系统，可以分成 6 个模块：

1. 数据层：行情 / 元数据 / 基本面 / 公告 / 预期数据
2. 因子层：技术 + 基本面 + 分析师预期 + 另类数据
3. 建模层：IC 检验、线性组合、ML 排序器
4. 风控层：中性化、行业约束、换手/容量约束
5. 回测层：T+1、停牌、ST、成本、分层/组合回测
6. Agent 层：Codex + AGENTS.md + skills + 报告生成

## 7. 课程项目要达到的最低标准

一个合格项目至少应回答下面 7 个问题：

1. 你研究的市场与标的是什么？
2. 你的信号/因子是什么？经济直觉是什么？
3. 你的标签是什么？为什么这样定义？
4. 你的样本切分与验证方式是什么？
5. 你的回测怎样处理 A 股约束？
6. 你的绩效如何？Sharpe / MDD / IC / turnover 如何？
7. 你的方法相对 baseline 提升在哪里？
